# V5.1：决策比较、福利成本与早期圣地机会

本修订保留V5的三层制度、合法战争路径、永久互斥路线、SSE和整批纠错。没有战争、宗教或政策选择配额。新局默认5.1，原比赛普通恢复保留原修订。

## 数值变化

最高福利每人口每100日由电力3／矿物2／食物2调整为**电力5／矿物3／食物5**；凝聚力贡献仍为+4。其余五档账单、工业惩罚、制度效果与考核门槛不变。集中配置见`src/shared/civilization.ts`的`DECISION_BALANCE`与`welfareRules`。

初始10人口、凝聚力60、没有新建设时，最高福利静态食物净收入为−26/100日；凝聚力100时仍为−10。库存能暂时覆盖赤字，不能据一次足额支付判断可持续。增加农业、能源设施及岗位可以承担最高待遇；不设置额外人口或建筑数量硬门槛。

新地图保留原有两跳以上圣地候选，另增加完整旋转对称的近边境候选组。新组距离最近母星恰好1跳，距离第二近母星不超过4跳、两者差不超过2跳，至少两个出口，不是母星。若没有合格组则按既有地图重试上限重试。只有探索完成才揭示，LRS不揭示；立教、所有权、殖民、祝圣要求不变。

## 统一比较与输入

- 全国比较提供当前及在建全部完工后的净收入、静态耗尽日数、步初可加工原料、合金吞吐、储备评分剩余空间。明确已排队船已付款。
- 福利三资源仍按共同比例支付；不足原因只列真实预算瓶颈。缺粮使共同支付下降时，不把充足的电力、矿物虚报为短缺；占领区无法交付单独记录。
- 建筑比较保留暂不建设、封存、调岗、岗位挤占及配套覆盖设施ID。材料回本只描述净矿物节省，不给加工、军力或民生强行定价；冶炼`paybackDays=null`不表示无价值。
- 文明比较包含保留当前状态、五档福利、立即路线及可执行的祝圣准备。祝圣只在已经发现、己方控制且已殖民的候选上，在私有草稿实际支付200矿物100食物并运行300日；不假设夺取敌方领土。军国另列战力、造舰、维护及准备优惠。
- 720／1440日经济预测列出已付款项目的模拟完成日期。生产、人口、项目与已提交政策推进；控制权、战争负担、危机及关系冻结。这些是条件性预测，不是未来收益承诺。
- 探索、建基地、殖民和合并可行性共用实际命令校验，依据己方状态和带日期的情报；查询在草稿进行。未知变化在共同结算复核，失败不扣资源。
- 模型输入通过`definitions`与`$ref`复用完全相同的对象。可无损还原全部目标、阻碍及时间戳，不截断候选列表。查询和界面展示同一计算结果的普通展开形式。
- 脚本在5.1下结合在建合金能力和净收入评估冶炼，降低无明确用途的过剩电力与已封顶矿物扩产权重。它仍是固定启发式，不代表模型选择。

## 修复与兼容

5.1按星系ID、行星ID统一排序同日人口结算记录，避免worker分区改变事件顺序。旧5.0保留原执行顺序与历史文件；其既有同日人口事件在不同worker数下可能顺序不同，原worker数可精确重放。

显式入口“以V5.1创建分支”保留原文件、资源、人口、队列、永久制度、战争、圣地及既得文明分，不补福利资源，不自动开局。5.0的民生考核历史从迁移日重新累计，灯塔连续计数重置但历史最高称号保留；永久乌托邦仍锁定最高待遇。原地图只添加满足对称条件的新候选，不重新绘图或搬迁已有圣地；无法添加时记录不可用。已探索的新候选只记录迁移当日勘察发现。

当前第60轮生产局保留5.0、保持暂停，不自动迁移。比较修复可用于其后续决策；新福利费用和候选分布只对5.1生效。
