# V5.3：治理质量、战争认知与并行建设

存档结构为5，规则修订为`5.3`。新比赛默认此修订。完整继承5.2的福利、永久路线、两个创教名额、文明责任和救援机制；不增加战争或路线选择配额。

## 治理质量与评分

`100×法理星系 + Q×(200×殖民地+5×人口) + 舰队分 + 储备分 + 战争成果 + 文明成果`

Q取最近72个实际十日区间的平均值。单步为「待遇系数 × 实际福利兑现 × 0.5^基础短缺种类数 × min(1,凝聚力/60)」。待遇系数：生存0.40、基础0.60、小康0.80、福利国家0.90、乌托邦1.00、教廷0.85。使用百万分之一定点，经济与凝聚力结算后采样。没有历史只显示当前估计，不补造样本。长期凝聚力为0可使社会资产分归零；不新增人口死亡或自动淘汰。

法理星系、舰队、储备及既有成果继续按原规则计算。危机与不满通过供应、凝聚力影响Q，不重复扣分。临时占领不转移法理分，无法交付的福利仍计入原主兑现不足。

## 军国阶段进展

实际总体战吞并且法理转移完成后，每个新星系立即军方不满−30，并授予360日压力缓冲。同一势力对同星系永久去重；收复母星或历史法理领土不算首次扩张，迁移前失去的领土同样不补奖。每方每战新增缓冲最多1080日，与交火缓冲分开记录。只在原本应产生压力时消耗，所属战争结束失效。临时占领、接触、第三方领土及计划意图均不触发。

完整责任仍在战后以实际保有总体战领土、兑现有限目标或成功防御判定。无成果主动战争仍增加20不满；阶段进展不额外授分。迁移不追补历史吞并。

## 停战及对手比较

- 无条件停战归还临时占领，保留正式吞并，放弃未兑现目标；签1080日互不侵犯。
- 强制议和显示已达标/未达标目标及条件性收益。赔偿仅显示0～200矿物，不查询敌方库存；最后领土与第三方变化共同结算复核。
- 疲劳与期限结算显示按当前控制进度的条件性结果，总体战无有限战争强制期限。
- 已法理取得或失效的宣称释放额度，历史事件保留。
- 传教责任可行动性不代表全部战争合法性；普通战争、宣称、征服准备分别列出。军情按舰队ID及日期去重，新的空军事记录不回退成旧守军；殖民与军事情报日期独立。航程是公开星图下限，不保证边境通行或到达日期。

## 指挥与施工

5.3每轮48条实际动作，结束回合独立保留；旧修订23条。单次输出上限8192token，仍最多3次请求、单次90秒、总决策180秒。SSE完整响应后整批校验；任何失败整批退回，从原轮边界重交。

`move_fleets`、`queue_ships_many`、`set_structures_status`按输入顺序展开，每个子项计一条。移动保留目标参数；每个造舰子项1～20艘，现有单船厂最多40艘排队限制不变。子项失败返回外层索引与子项索引，不重复支付。

每行星地表、轨道各2条建筑/扩槽施工线。按创建日期、项目ID排序，步初冻结，空位下一十日接续。造舰默认1条线；本地干船坞正常满员、未封存/重启、供电与矿物维护正常时开放第2条。原25%速度加成保留；失效时后续项目暂停但保留进度。新完工干船坞下一步才生效。

岗位、价格、预付款、建筑槽、维护不变。占领暂停、整合减速继续适用；探索、殖民、祝圣固定工期且独立。静态完工日期明确标注效率冻结假设，720/1440日预测使用真实并行推进。

## 配置与实现入口

新增数值集中于`src/shared/governance.ts`的`V53`。修订能力继承在`src/shared/responsibility.ts`集中判断；动作与输出额度通过`actionLimit`和`outputLimit`生成。岗位、福利、战争旧数值仍由原配置负责。

治理、结算及施工共有实现分别为`governanceView`、`settlementPreview`、`constructionView`；AI首轮、查询和UI复用。审计包含治理样本、施工进度、阶段战果来源/去重键/前后不满/缓冲。外国精确治理分解不向势力视角展示。
