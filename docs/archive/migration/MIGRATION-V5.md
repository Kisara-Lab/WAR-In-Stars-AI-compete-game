# V5迁移与上线

- 普通恢复不升级V4及其修订。原始回合、哈希、结果保持不变。
- 存档/复盘界面的“以V5创建分支”或 `POST /api/load {"id":"原比赛ID","round":60,"rulesRevision":"5.0"}` 明确创建新ID、暂停的分支；原档先通过哈希校验。禁止降级修订。
- 已结束比赛不迁移继续，不改写获胜者。
- 原国教→永久国教/教廷保障；原世俗→普通世俗/均衡小康，分支首决策可首次选待遇。旧乌托邦政策不作永久承诺。
- 旧长期政策和预约终止并写事件，新政策从不采用开始；当前日历任期未结束前仍遵守锁定规则。
- 过去文明成果、历史灯塔称号保留；新制度资格及新评估不追补。已有资源、人口、战争、条约、圣地、危机、项目、就业保留，不补发福利物资。
- 普通恢复和同修订分支不重复初始化制度，不能用恢复改宗。

上线前暂停活动局并等 `busy=false`，调用保存，记录ID/轮数/状态哈希；重启后核对相同ID/轮数/哈希。旧4.3第60轮不自动迁移。本次授权的真实V5观察局为同种子独立新局，到60轮自动停止推进并保存；若提前结束则保留结果。

配置示例见 `config.v5.example.json`。原配置文件不需新增认证项，继续使用本地AIKEY.env。密钥不写入存档、报告或编年史。
