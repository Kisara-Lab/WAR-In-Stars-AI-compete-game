# V4：战争目标、永久国教与文明灯塔

V4在V3的经济、短缺、LRS、两年政策和审计机制之上扩展。默认四方、24星系、120轮；一年360日，每轮100日，内部每步10日。新数值集中于 `src/shared/v4.ts`，经济及时间基准见 `src/shared/rules.ts`，两年政策见 `src/shared/civil.ts`。

## 战争与和平

| 类型 | 条件与目标 | 收益 |
| --- | --- | --- |
| 总体战 | 有效重大理由，无有限目标 | 可直接吞并、淘汰对手 |
| 有限军事战 | 一个邻接敌方基地 | 基地停用300日，最多200矿物赔偿，不割地 |
| 宣称夺取战 | 一至两个预先宣称的邻接敌方星系 | 仅目标可割让 |
| 传教战 | 国教国家、一个邻接敌方殖民星系 | 1800日传教权，不改变对方制度 |
| 保卫思潮 | 己方殖民星系有对方传教权，或其影响达到20 | 清除目标教派影响和权利，保护1080日 |

宗教国家的保卫思潮亦称信仰保卫战。所有目标取自本方情报；共同提交时复核真实世界，过时命令可能被拒绝并记录原因。无效命令不消费资源。

宣称每处100矿物、有效1800日，最多两处，创建的下一决策回合才能用于战争。母星和对方最后一个法理星系不能通过有限战争割让。战争期间不得增补目标、升级或更换类型。非目标军事行动合法，但战后不得索取未声明收益。

### 重大理由

- 对方占有本国初始母星。
- 对方通过V4战争正式夺取本国至少两个星系，且仍持有。
- 已祝圣主圣地被对方连续控制300日。
- 遭受对方发动的总体战。

前三类在原因消失后保留1080日；遭受总体战的理由在战争结束后保留2160日。理由不绕过互不侵犯，也不允许正在进行的有限战争升级。同轮双方合法宣战合并：一方合法声明总体战则形成总体战，否则各自保留有限目标。

### 首次接触与有限战争结束

首次接触允许交火，但生成无割地目标的边境冲突，最多900日。正式和平后必须宣战。双方确认和平、停战提议下一轮接受、提议300日有效及单向通行制度继续保留。

进攻目标需连续控制基地200日；保卫思潮需连续控制目标200日且没有战争对手舰队。中断立即重计。全部目标达标可 `enforce_peace`；疲劳达到100或非总体战持续2160日时自动结算，兑现已达标目标，其余无收益。全部目标被第三方吞并等原因判无效时，无收益结束。第三方控制不算己方控制。

战争疲劳每100日增加3，另加4乘被对手占领的法理基地比例。舰船损失按剩余船体折算矿物价值，再乘40除以开战军力价值；分母最低180，同一战争每100日最多增加40。只归因到实际造成损失的双边战争。

所有停战签1080日互不侵犯、取消双方追击并执行撤军。无条件协商停战不兑现有限目标；总体战保留已经正式吞并的领土。总体战不受疲劳及2160日强制结算限制。

### 法理归属与军事控制

`ownerId` 是法理归属；`controllerId` 在发生占领时记录军事控制，未单独记录时等于法理所有者。基地参与控制方的战斗，通行按实际控制方判断。

临时占领时：

- 原主保留法理领土、人口和项目；项目暂停，双方均不能下达建设、拆除、殖民和造舰。
- 占领方获得正常产出的25%，使用其生产倍率并承担维护及人口食物。
- 人口增长、LRS暂停，基地可维修控制方舰队。
- 人口仍属于法理国家；原建筑凝聚力贡献暂停，改为−2的行星贡献，再按人口加权。
- 非总体战基地同归于尽时停用100日，恢复50%船体；不会因此灭国。
- 正式割让才转移殖民地并取消原主未完成项目，不退款。
- 第三方击败占领军，若与法理国家和平，只能解放归还。

非总体战即使全部基地被占也不淘汰。紧急撤离没有可用基地时，舰队在场外等待，恢复基地后返回；不生成舰船或资源。评分按法理领土计算。

## 永久国教与圣地

国教独立于720日政策。必须发现可抵达的候选才能确立；国教、教名和主圣地不可更换，永久禁止乌托邦和文明灯塔。当前或已预约乌托邦时不能立教。宗教名称和公开教义只用于叙事，不能赋予自定义能力。

新地图候选不是母星，距最近母星至少两跳，至少两个出口；第二近母星不超过四跳，两方距离差不超过一跳。候选按旋转对称组生成并参与地图重试验证。每候选星系种子选择一颗行星，完成探索才揭示，LRS不代替探索。扩张后成为腹地的圣地不搬迁。

每国教有一个永久主圣地，最多两个附属圣地。发现候选即可立教，未祝圣不受失守惩罚。祝圣需法理所有、实际控制且有殖民地，花费200矿物、100食物，固定300日，不占建筑槽。失去控制取消施工且不退款。首次主圣地祝圣危机−5，附属各−2。不同宗教可历史上认定同一行星为圣地。

### 信仰危机

| 危机 | 凝聚力/100日 | 生产及建设 | 战力 |
| --- | --- | --- | --- |
| 0–19 | +4 | ×1.00 | ×1.08 |
| 20–39 | +1 | ×0.95 | ×1.00 |
| 40–69 | −4 | ×0.85 | ×0.90 |
| 70–100 | −8 | ×0.70 | ×0.75 |

正凝聚力收益受短缺倍率修正，负贡献不减轻。战力与船体、短缺、政策相乘，战损换算使用相同完整倍率。每十日步冻结倍率，当前步危机变化下一步生效。探索、殖民和祝圣不受效率工期修正。

- 舰船损失：40乘损失船体对应矿物价值，除以战前全国现存舰队船体价值；分母最低180，每100日最多+30。
- 主圣地失守+30，持续每100日+4；附属失守+15，每100日+2。
- 对手兑现目标、主动战争没有兑现收益，各每场+10；传教目标达成−8。
- 主圣地收复−15，附属−7；按战争和圣地分别最多记录一次，不能反复刷收益。同一步失守、收复仍逐次记录。
- 全部供应正常且圣地安全：和平每100日−2，战争每100日−1。
- 所有变化先汇总，再统一限制在0～100；修船不直接退还危机，没有强制随机崩溃。

### 教义争端

主圣地失守300日、危机≥40持续200日、外国宗教人口加权影响≥20%持续300日，任一可触发争端。同时最多一个，同原因解除并稳定300日才重新触发。未回应每100日危机+2。

| 回应 | 费用与效果 |
| --- | --- |
| 调和教派 | 100矿物、200食物；300日内额外−4危机/100日 |
| 教义改革 | 300日内额外−6危机/100日；720日暂停宗教正凝聚力及战力收益，负惩罚保留 |
| 坚持圣战 | 300日额外战力×1.05；720日内收复绑定主圣地或兑现当时声明的进攻目标，成功−5、失败+15 |

回应结束当前争端，不能叠加或取消，720日内不能再次获得回应。没有可绑定目标不能坚持圣战。未决新争端仍产生压力。

## 地方传播与文明灯塔

传教影响按行星和来源宗教记录，总和最多100。传教胜利使现有殖民地该教影响至少20；1800日权利期每100日+5，新增殖民地从0开始。上限时按比例挤占其他教派，固定顺序处理余数。到期每100日−2。第三方割让终止不约束第三国的旧传教权，但居民影响保留。

外国影响按殖民人口加权：世俗国家凝聚力每100日−4乘影响比例，国教国家危机每100日+4乘异教比例。本国国教不计外国影响；被占领行星暂停传播及影响惩罚，改用占领和圣地规则。传教不提供敌方经济、人口、指令或队列。

思想整合每星系100矿物、100食物、持续720日，每100日额外清除3点外国影响，按占比分配，不叠加、不取消传教条约。三年互不侵犯后可发动保卫思潮，获胜清除目标教派影响和权利，并给予目标星系1080日新传教保护。

乌托邦每届必须完整720日，至少90%的十日步三种供应均正常，且没有主动发动总体战，才算合格。连续完成两届：随后乌托邦额外凝聚力+1；三届及以上+2，电力/矿物产出倍率0.75→0.80。正收益受短缺影响。政策中断或不合格任期清零，奖励不追溯；历史最高等级保留。国教永远失去资格。

## 工具、日志与兼容

新工具：`create_claim`、带目标的 `declare_war`、`enforce_peace`、`get_wars`、`get_faith`、`establish_religion`、`consecrate`、`respond_dispute`、`integrate_thought`。单工具与批量Schema同步；具体参数例见 `examples/v4-actions.json`。AI有全部数值、自身危机分解、战争目标及灯塔进度，自行决定路线。

JSONL增加 `event.war`、`event.religion`、`event.beacon`，保留目标、理由来源、战损分母、危机封顶、占领/割让、教义原文、争端及任期评估。历史事件保存值快照，不引用可变世界对象。编年史增加战争及和约、国教与圣地、文明灯塔章节；失败尝试仍不计入历史事实。

V4状态哈希使用排序对象键的规范化JSON；V1～V3仍用原算法验证，不重算旧历史。恢复创建V4新分支，现有战争标为历史兼容总体战，旧地图和政策保留。灯塔从下一完整任期计算，旧宗教及理由历史不补造。候选不合格可使用兼容条件：距离母星至少一跳、最近双方距离差最多两跳，其余保持；仍无候选则记录本局无法立教。已探索星系在分支创建日记录新规则勘察发现。

浏览器默认全图观察；选择势力后，地图、行星、事件、战争和文明面板展示该势力已知资料。完整审计及导出仍是人类观察者的全局档案入口，不提供给模型。
