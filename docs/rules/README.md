# 当前玩法与规则 / Current gameplay and rules

**新比赛默认规则5.4，存档结构版本5。** 历史修订文档说明各阶段新增规则；当前新局按继承后的5.4配置运行，旧文档中的“默认”“新版本”仅指当时修订。

New matches use rules **5.4**, save structure **5**. This page summarizes the current game. Detailed historical specifications below are in Chinese and apply to their named revisions.

## 回合、地图与情报

- 4～8方，地图星系数须与人数匹配。默认4方24星系120轮，每轮100日、每步10日。
- 开局地图以种子和旋转对称规则生成。探索、基地、舰队与满员LRS提供不同情报；LRS不揭示行星禀赋与圣地候选。
- 所有势力使用同一轮边界决策。最多48条实际动作、3次模型请求；完整批次失败则回滚，四方或多方有效计划共同结算。

## 文明与民生

普通世俗可暂不承诺；确立乌托邦、军国主义或国教后永久锁定且互斥。五档世俗待遇与教廷保障实际消耗电力、矿物、食物，按人口计账。基础维护优先，三种福利资源按共同兑现比例支付。

乌托邦需要持续高福利与考核，禁止主动征服准备，但可以进行其他合法战争；军国有战力、造舰和准备优惠，以及维护与军事责任；国教依赖已控制、独占登记的创教候选、固定主圣地与传教成果。全图恰好两个创教候选，附属圣地不提供额外创教名额。

两年政策每720日选择，加强演习、对外交流、子空间监听或不采用。它与永久路线、福利档位分别管理。

## 岗位与产业

每人口提供1劳动力，按行星分配到地表和轨道设施；AI设置类别优先级。缺员按运营比例降低效果，封存设施仍有维护。全国资源包括电力、食物、矿物与合金，矿物加工为合金后才能持续造舰。

每行星地表、轨道各2条建筑施工线；满员且正常供给的干船坞开放第2条造舰线。排队项目预付资源、预留槽位；增加槽位不增加人口。居住设施、禀赋与配套鼓励不同的建设组合。

## 战争与外交

| 类型 | 主要结果 |
|---|---|
| 宣称战 | 声明目标达到控制要求后正式割让 |
| 有限军事战 | 兑现非领土军事目标 |
| 传教战 | 获得目标传教权 |
| 保卫思潮 | 对传教与思想争端的规则内反制 |
| 民生救援战 | 改革或停止征收协议，不割地 |
| 总体战 | 有重大理由时正式吞并，承担维护与吞并整合成本 |

互不侵犯仍约束宣战。无条件停战归还临时占领，保留已正式吞并；强制议和按目标控制进度兑现。总体战的 `systemIds` 必须为空数组，进攻目标另用移动表达。法理归属与军事控制分开记录，临时占领不能直接灭国。

## 5.4救急与干预

国教每局一次特殊什四税救急，最长1800日，可提前停止；提供限定基础经济补助和社会恢复轨迹。它没有真实资源来源，不补贴任意扩军与建设。征收引发乌托邦停止通牒，接受后进入原期限内渐退恢复；拒绝可产生合法救援战争路径。详见 [5.4规则](RULES-V5.4.md)。

## 评分

`100 × 法理星系 + Q × (200 × 殖民地 + 5 × 人口) + 舰队分 + 储备分 + 战争成果 + 文明成果`

Q为最近720日十日样本的平均治理质量，综合待遇、福利兑现、基础供应与凝聚力。资源储备按矿物加两倍合金合并递减计分、最高400。文明成果共用1500上限，战争成果按类型、目标及历史去重。建筑数量本身不加分。
