# V5 / 5.0：永久文明、待遇与两年政策

新局默认存档版本5，规则修订5.0。旧档普通恢复保持原规则；显式分支见 [MIGRATION-V5.md](../migration/MIGRATION-V5.md)。V4.3的人口岗位、全国合金、施工队列、对称禀赋、战争目标、战争开支和吞并整合继续适用。

## 三层制度

普通世俗可一直不承诺；乌托邦共同体、军国主义、永久国教三者互斥，明确确认后不可撤销。待遇与政策分别记录。最高待遇不是自动建立乌托邦，重工业不直接禁止高福利。

### 民众待遇

每人口每100日额外账单；全国凝聚力贡献只算一次。

|待遇|电力|矿物|食物|凝聚力|
|---|---:|---:|---:|---:|
|维持生存|0.25|0.10|0.25|−3|
|基础保障|0.50|0.25|0.50|−1|
|均衡小康|1.00|0.50|1.00|0|
|福利国家|2.00|1.00|1.50|+2|
|乌托邦社会|3.00|2.00|2.00|+4|
|教廷保障|1.50|0.75|1.25|+1|

默认均衡小康，首次选择可立即进行，后续调整锁定360日。普通世俗和军国可选五档世俗待遇；乌托邦锁最高，国教锁教廷。制度要求优先于待遇冷却。

每十日：生产及原有维护→福利→步初矿物约束下的冶炼→维修。三项福利按共同支付比例缩减，不负库存、不借债、不自动降档。正福利凝聚力乘兑现比例及基础短缺倍率，低待遇负贡献不打折；另扣 `6×未兑现比例/100日`。工业惩罚另列。占领区法理人口计失约但不扣不能交付的物资；吞并在当步经济结算前纳入新国家账单。人口增长后新增人口从下一个十日区间计费。

### 乌托邦共同体

须普通世俗、最高待遇连续720日、最近72步至少65步同时福利足额/基础供应正常/凝聚力至少80、当前供应及兑现正常、没有有效征服准备。须先明确撤回准备，再确认制度。无旧电矿产出折损。

福利及基础供应正常时增长×1.15、全国凝聚力+2。连续完成2/3个合格720日历评估期，灯塔另+1/+2凝聚力；没有资源倍率。未满完整评估期不补奖。失约及短缺暂停正奖励；不合格评估清零连续进度，不扣已获文明分。每合格期100分。

**乌托邦可以参战。** 宣称割地、有限军事、保卫思潮、防御战争及凭有效重大理由的总体战均按通常规则校验；只禁止主动征服准备。参战本身不取消民生评估资格。

### 军国主义

普通世俗明确确认即可建立，无军力或战绩前置。舰队及基地战力×1.10、船厂进度×1.15、全舰电矿维护×1.10、矿场及冶炼工业惩罚×1.25。没有全国产出加成。维护先叠战争及演习倍率，再应用驻留维护站折扣。准备征服180日、150矿物、50食物、5凝聚力；仍需和平接壤、另行宣战、遵守条约。不开战不额外受罚，可付最高福利但不能转乌托邦。

### 永久国教

仅普通世俗可立教；保留探索候选、可达路径、永久主圣地、祝圣、传教、危机及争端。锁教廷保障，失约额外危机 `2×未兑现比例/100日`。低危机战力×1.08；已祝圣、安全且危机<20的主圣地使全国产出×1.10。未祝圣不承担失守惩罚。完整稳定信仰期须至少90%区间供应正常、福利足额、危机低于20、主圣地安全；每期100分。

乌托邦/信仰已得任期分保留，与动态主圣地200、附属圣地每处100（最多两处）共用1500文明分上限，任期按势力、类别、编号去重。

## 两年政策

|政策|效果|
|---|---|
|加强演习|仅舰队战力×1.03；全舰电矿维护×1.05，不加成基地|

|子空间监听|正常运营、满员、供电维护正常LRS的维护×0.85；仍两跳|
|不采用|无效果|

任期720日，可提前预约下一届，无自动续期。人口综合倍率最高2。政策在期限到达前的十日区间结算完后切换。

## 决策信息与执行

`get_options/get_wars/get_faith/get_industry/get_civilization`、首轮模型输入及观察界面共用比较计算。可见的宣战目标、先宣称/先准备路径、阻碍、日期、费用、收益同时列出。敌军按ID和时间戳去重，局部守军与增援分开，不读取隐藏总军力。

产业比较包含不建设、建设、封存、重启、调岗；已排队建筑计入未来岗位占用和产能。船舰队列材料已预付。静态比较不保证未来收支。720/1440日预测只推进本国已知已付款项目、人口、经济、明确的制度/政策假设；冻结控制权、战争开支、关系及信仰危机，不预测敌军和胜利。政策预览若无选择窗口仍明确标为不可立即采用。所有试算为独立草稿。

模型使用 Responses SSE，整批退回重交；每方最多3请求、单请求90秒、总决策180秒。任一势力预算耗尽，本轮整体不提交。只在完整有效计划后提交；错误摘要不视为已执行。服务在审计、保存和收尾结束后才公布空闲。
