# V4.1：宿敌、征服准备与战争成果

沿用V4的战争目标、占领、国教、政策及三年互不侵犯。存档结构仍为版本4，以 `rulesRevision: "4.1"` 区分新规则；缺失修订号按原V4处理。新增数值集中于 `src/shared/escalation.ts`。

## 宿敌

每对势力累计完成3场发生实际船体损失（含基地）或基地占领的正式战争，双方获得宿敌总体战理由。首次接触冲突和空战争不计数，同一战争仅记一次。

只有双方和平且没有互不侵犯的时间才计入自由和平；连续1080日清除宿敌及累计战争。条约期间暂停计时，重新进入双边战争时清零，第三方战争不影响本对关系。因此第三场战争结束后，先遵守1080日条约，随后仍有完整1080日的理由窗口。

宿敌不自动宣战、不突破条约、不允许战争中升级。理由ID由 `get_wars.escalation.reasons` 或每轮输入的 `escalation.reasons` 提供。

## 公开征服准备

- `prepare_conquest({ factionId, reason })`：双方正式和平，存在本方情报确认的法理接壤；每方最多一个活动准备。最终提交再复核实际边境。
- 一次支付300矿物、100食物、10凝聚力，资源含本轮预留，凝聚力不足10不可启动。
- 准备360日，每100日额外凝聚力−2；精确按36个十日区间计算，不提供额外生产或战力加成。
- 可以在条约期间准备，成熟后仍须等条约到期。成熟资格有1080个无条约和平日有效期，届满失效。
- 用成熟资格ID作为总体战的 `grievanceId`，另行调用 `declare_war`。征服准备和宿敌都只是可选理由。
- 对该目标宣战后消耗准备；双方进入其他战争、任一方淘汰、主动撤回或资格过期时取消，不退款。与第三方发生战争不自动取消。
- 失去接壤时暂停使用资格，有效期照常消耗。过时情报可让预校验通过，但共同提交会复核；不会通过工具读取敌方隐藏军力。
- `cancel_conquest({})` 撤回准备或成熟资格；同轮不能重复准备或把准备与撤回混用。
- 同轮先处理宣战，再处理准备；战争发生后准备失败不收费。AI每轮独立观察，不提前接收对方暂存命令。
- 1.5倍军力只是按已知军情评估的建议，允许冒险和误判。精确敌方全国军力不是合法性门槛。

准备、成熟、失效和公开理由只告知相关双方。观察者可看全图；势力视角不展示无关双边资料。

## 新终局评分

`100×法理星系 + 200×殖民地 + 5×人口 + 0.5×基础舰队战力 + 矿物/10 + 战争成果`

| 成果 | 分数与限制 |
| --- | --- |
| 宣称正式割让、总体战吞并 | 每星系100；本方对同一星系只登记一次，当前仍法理持有才计分 |
| 有限军事、传教、保卫思潮目标兑现 | 每目标50；按本方／对手／星系／目标类型去重，本方总计不超过500 |

领土丢失不计成果，收复恢复原登记资格但不叠加。临时占领、普通击杀、赔偿、无条件停战及接触冲突不发额外分；总体战在无条件停战前已经发生的正式吞并仍按持有情况计分。所有奖励来自实际提交结果，不从意图推断。

国家卡和结果榜展示法理领土、殖民地、人口、舰队、矿物、领土成果及目标成果分项。军事与经济仍可和平积累，降权不等于消除囤舰策略。

## AI、审计和兼容

新增工具覆盖单工具、批量Schema和原子资源预留。AI输入包含双边累计、自由和平、条约日期、资格可用日期、当前准备、代价和自身分项评分；脚本按已知舰队去重估算风险，不读取隐藏总军力。主动发动总体战仍使乌托邦当届不合格。

审计记录准备成本、成熟、计时、取消原因、宿敌来源及战争成果，编年史增加“宿敌、征服准备与战争成果”。准备、宿敌和成果状态进入哈希及恢复。

旧档原始文件和结果不修改。加载未结束旧局时创建4.1新分支，保留既有战争、理由、条约、政策；新增计数和成果从迁移日起开始，旧战争只有迁移后发生实战才可能计入。已经结束的历史局保留原修订、原评分和获胜者。恢复4.1快照时保留全部进度，不重复迁移。通过旧版逐轮命令重放检查原V4哈希兼容性。
