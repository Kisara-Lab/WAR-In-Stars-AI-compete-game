# Assets and dependencies / 素材与依赖

- The galaxy, planet, fleet and interface graphics are rendered by the project using Canvas, CSS, text and interface components. The public source contains no bundled third-party raster art, fonts or audio files.
- The three PNG files in `docs/assets/` are selected screenshots of this project's real match observer. They are included under the project license and show fictional game state, not API credentials.
- The project uses Node.js, TypeScript, React, Vite, Express, ws, Zod, dotenv, Vitest and Playwright. These packages retain their own licenses; exact dependency versions are recorded in `package-lock.json`, and installed packages include their license notices.
- GitHub Actions and Shields.io provide the README badges. Product and model names identify their respective products and do not imply affiliation or endorsement.

界面与星图由项目自身代码绘制；公开截图来自真实观察台。依赖库按各自许可证分发，项目MIT许可证不替代依赖的许可条款。项目未打包外部商业游戏素材。
