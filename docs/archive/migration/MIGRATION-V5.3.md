# V5.3迁移与部署

- 普通恢复保留原规则、评分和工具；新比赛默认5.3。
- 存档页选择历史未结束回合，点击「以V5.3创建分支」。API为`POST /api/load`，参数`{"id":"原比赛ID","round":119,"rulesRevision":"5.3"}`。生成新ID与来源哈希，保持暂停。
- 已结束终局不能直接迁移继续运行；可选择其未结束历史回合显式创建分支。不会自动重开比赛。
- 继承5.2兼容约束：超过两个国教的旧局不能迁移，候选不合规且无法补足时拒绝；不会剥夺既有制度。
- 5.2→5.3保留资产、人口、项目进度、预付款、战争、条约、制度及责任历史。释放已完成或失效宣称并记录事件。
- 治理历史从分支迁移日开始，没有历史时显示估计。阶段进展去重账本从迁移日起建立，不补发既有吞并降压或缓冲。双施工与干船坞第二线从新修订开始计算，不补发过去工时。
- 新状态进入标准状态哈希、原子存档与复盘；旧修订不写入新样本。
- 服务恢复已结束比赛时保持原文件及审计链，不向已结束档案追加恢复事件。运行维护记录保存在本次验证目录。活动局部署前须暂停、等待当前决策退出并保存轮边界。

离线重算仅输出独立报告，不改原胜者、原档或历史哈希。迁移和验证不应自动追加真实模型比赛。
