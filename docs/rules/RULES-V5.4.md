# V5.4：什四税、停止通牒与受监督恢复

存档结构版本5，规则修订5.4。新比赛默认5.4；旧比赛普通恢复保持原修订。继承5.3岗位、产业、治理评分、48条动作、双施工线、SSE整批回滚及请求预算。

## 一次性救急

永久国教可随时提交 `activate_extraction {}`。每国每局一次，从下一十日区间起作用，原截止日为启用日加1800。什四税是**无资源来源的特殊规则**，不是正常税基、生产加成或40%实收税款。

电力、矿物、食物分别结算，内部资源单位仍为千分之一：

`本步补助 = round(max(0, 合格基础维护 + 可交付教廷福利 × 1.10 − 正常生产))`

- 基础维护包括实际设施、人口和启用时已有舰船。原舰船按ID登记，保护额度取启用时不含战争倍率的维护；随后最多支付实际维护、当前非战争维护、原额度三者的最小值。
- 舰船合并、拆分不改资格；新舰船和已消失舰船不补助。维护站折扣及在途维护沿原规则。
- 不支付额外战争维护、维修、建设、命令、造舰或冶炼原料，不创造合金。
- 无法交付的占领区福利不获补助，但仍记入原国家失约。
- 主线程在基础维护和福利付款前把补助计入本步收入。它不成为本步可抢用的步初冶炼原料；后续实际积累的库存可以正常使用。
- 正常生产、补助、合格开支及未覆盖维护分列。额外开支仍可能导致总收支负数，不能把本规则理解为无限军备报销。

每十日先做普通社会结算，再应用1800日线性轨迹：危机上限由初值下降至 `min(初值,19)`；凝聚力下限由 `min(初值,60)` 上升至60。高于下限的实际凝聚力保留，不锁定初始高值。新增传教逾期压力暂停至原截止日；旧逾期、成果及其他责任日期不清零。

征收区间的治理质量Q最高0.50，再进入原720日滑窗。任何与征收重叠的稳定信仰任期失格，已取得成果不删除。

## 停止要求及战争

正式接触国家收到公开事件；新接触时补发。只公开事件日期、停止情况及本方相关通牒，不公开外国舰船保护清单、库存、精确补助或危机。

乌托邦从获知事件或确立路线的较晚日期起，须在180日内提交：

```json
{"type":"demand_stop_extraction","args":{"factionId":"umbra","eventId":"查询返回的征收事件ID"}}
```

目标有180日接受，可用 `accept_stop_extraction {demandId}` 或 `reject_stop_extraction {demandId}`。明确拒绝提前开放救援理由；晚拒绝、重复要求都不能延后原截止时间。只能回应先前收到的要求。

通牒失败且有合法路径时，乌托邦自行提交 `declare_war`：`warType:"humanitarian"`、一个已知可达边境殖民目标、`grievanceId`填写征收事件ID。互不侵犯仍禁止战争；未知目标、不可达或既有战争不能被当成可宣战路径。钱少、舰少不免除责任。没有新强制自动宣战。

未及时提出要求，或合法可行动却不行动，沿用救援责任惩罚：暂停灯塔、当前期失格、每100日扣50文明分，最高300，与普通关注不叠加。空宣战不算进展；实际敌对行动最多缓冲720日。普通援助或改革提案不能替代停止要求。

救援战争不割地。连续控制声明目标基地200日，可通过原 `enforce_peace` 入口订立停止协议；目标也能用 `accept_reform {proposalId:战争ID}` 提前接受。强制取得协议按原非领土去重规则最多给该目标50分；谈判、重复停止、第三方失效目标均不授分。

**无条件停战不会强制停止征收，也不代表救援责任已完成。** 停止协议成立后归还相关救援战争临时占领，签1080日互不侵犯，并监督实际福利。多国共用同一事件和停止结果，不重复授分。

征收停止或到期后，旧事件不能再用于宣战。监督协议违约产生独立理由，不能突破条约，条约到期后保留完整1080日窗口。

## 退出与监督

`stop_extraction {}` 主动停止，或接受／被迫接受停止协议，都会永久结束征收，不重开、不延期。不能在同一批先启用再停止；只能停止轮边界已存在的征收。

- 舰船补助立即撤销。
- 保留人口基础消耗、民用设施、永久扩槽维护和可交付福利的托底；不覆盖基地、船厂、干船坞、舰队维护站或LRS维护。
- 不再增加10%福利储备；民生缺口补助乘 `(原截止日−本步起日)/(原截止日−停止日)`，停止当日比例为1，原截止归零。
- 社会恢复及传教压力暂停仍到原截止日结束。
- Q恢复真实采样，旧低质量样本自然退出；新的稳定信仰奖只来自完全不含征收区间的合格任期。
- 有协议时沿用1080日监督、前180日恢复和滚动360日90%检查。连续360日可服务居民福利足额、基础供应正常，才完成停止征收救援责任。无可服务人口不刷合格天数。

预测展示当前托底和撤去补助后的静态对照；720／1440日预测会经过真实原截止日，但不假设外国接受协议、未来战争胜利或未知资产。

## 配置、接口和审计

参数集中在 `src/shared/emergency.ts` 的 `V54`，成本和战争常量继续使用已有统一配置。

新命令为 `activate_extraction`、`stop_extraction`、`demand_stop_extraction`、`accept_stop_extraction`、`reject_stop_extraction`。单工具及唯一 `submit_turn` 批量Schema同步；旧修订不下发新工具。查询并入 `get_responsibilities`、`get_civilization`、`get_wars`、`get_faith` 与首轮比较。

接受停止、主动停止先于普通命令共同结算，之后宣战重核理由。审计记录事件ID、原截止日、舰船资格、应补／实补、社会修正前后值、通牒与责任依据；私有经济细节只对本方可见。编年史只采用世界执行事实。
