# V4.3 人口岗位、产业链与行星专精

新建比赛修订号4.3；V4.2战争、宗教、政策、文明分继续适用。资源全国共享，不增加运输船。专精是实际建筑和就业组合，没有专精按钮或隐藏加成。

## 人口与运营

每人口1岗位，地表与轨道共享本行星劳动力。优先级0～5，数字越大越优先；同级按需求比例分配，千分之一岗位的余数按建筑ID固定分配。每十日冻结一次。

原设施岗位：农场2、矿场2、太阳能1、船厂1、疗养所1、度假区2、LRS1。默认优先级：电粮5、矿4、民生传感3、冶炼2、船厂及配套1。无岗位的居住设施不占劳动。

产出、加工、民生效果、船厂进度和辅助效果随运营率缩减。LRS需满员及电力/矿物维护正常。普通设施维护为20%＋80%×运营率；封存维护10%，无效果；重启100日，期间20%维护。居住建筑运行时全额维护。

开局母星增加1冶炼厂、100合金；初始设施合计10岗位。人口基础上限16，居住区与居住环各加4，最高24。人口增长综合倍率最多2，吞并整合再按原规则缩减。人口超过当前容量时停止增长，不删除已有居民。

矿业惩罚按实际开采矿场当量计算，前2座当量免费、超出每座−2；冶炼每座满运营另−1。民生收益和工业惩罚仍按人口加权，穷兵黩武放大矿业及冶炼惩罚。占领/吞并整合使用原有替代凝聚力贡献。

## 合金与施工

驱逐舰20矿+20合金、巡洋60+60、战列160+160、无畏400+400。按2矿物/合金计算，等效基础材料价值不变；战损、疲劳和危机继续使用原等效价值。日常舰船维护不改，维修使用新材料比例，任一材料不足按可负担比例修复。

冶炼投入与产出同步乘岗位、凝聚力、供应、信仰、圣地协作、占领及吞并整合倍率。不重复乘资源政策或精炼倍率。主线程按步初库存与当前可用库存较小值，先保留实际矿物维护，再向所有冶炼需求同比分配；不借本步矿产或战后赔偿扩大本步加工。合金不足不增加全国短缺类型。

地表、轨道各串行施工，按创建日期、ID排序；造舰独立。新完工设施下一步参与岗位分配。探索、殖民、祝圣保持固定工期。排队预付全部资源并占用未来槽位。取消返还原实付50%；拆除设施返还矿物和合金基础造价25%。

扩建不占槽位，进入对应施工队列，每条扩建路径不能重复排队。完工永久保留，不赠送劳动人口。

## 禀赋与评分

行星最多一种禀赋：普通、富矿、肥沃、强日照、宜居。对应矿场/农场/太阳能产出或人口增长+15%；生产禀赋与对应本地配套百分比相加。母星系行星为普通，其余按旋转对称组与种子确定。探索才揭示，LRS不揭示。

储备价值=矿物+2×合金；前2000价值每10计1分，再8000每40计1分，其余0分，最多400。建筑数量不计分。旧修订仍使用旧矿物库存分。舰队、殖民地与文明成果等分项未变，不能据此声称全部囤积或扩张策略已平衡。

## AI、界面及记录

新增工具：`get_industry(planetId|null)`、`set_jobs(planetId,structureType,priority)`、`set_structure_status(planetId,structureId,sealed)`、`expand_slots(planetId,slot)`。建设比较包括等待、费用、当前可建性、完工假设净收支、挤占岗位与矿物等价静态回本，不保证未来收益。批量Schema及SSE整批回滚包括合金。

界面显示岗位、封存/重启、队列、禀赋、扩槽、合金及储备分；势力视角不显示对手内部岗位。审计记录每步岗位、运营维护、生产、冶炼需求/分配、维修材料。编年史区分建成与实际运营，不额外调用模型。
